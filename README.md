# DogecoinCash.com information portal

A mobile-friendly informational website for holders of restricted book-entry Units issued by Dogecoin Cash, Inc.

## Purpose

The site distinguishes among:

1. Dogecoin Cash, Inc. (DOGP)
2. Restricted book-entry Units issued to eligible shareholders
3. The independently developed DogeCoin Cash (DOG) BEP-20 token

It does not claim to be the official developer website for the DOG token.

## Live data

Market data is retrieved client-side from DexScreener for the confirmed BNB Smart Chain contract:

`0x9596a56c73CA6f50CBd05cB8D85865F75659dC78`

Visitors are directed to independently verify the contract on BscScan.

## Files

- `index.html` — site content and structure
- `styles.css` — responsive visual design
- `script.js` — live market data, copy button, and mobile navigation

No domain or public hosting configuration is included yet.
